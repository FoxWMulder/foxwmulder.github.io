[Link Shell Extension](https://schinagl.priv.at/nt/hardlinkshellext/linkshellextension.html)   
  
1)  
RBM on source folder/file > click "Pick Link Source"  
![](attachments/Pasted%20image%2020250714045741.png)  
  
2)  
На папке/диске где будет создана Symbolic link, RBM > choose "Drop AS..." > click "Symbolic Link"  
![](attachments/Pasted%20image%2020250714045851.png)  
  
Если исходным был выбран не папка, а файл, то пункт меню "Drop AS..." будет отсутвовать, а будет пункт меню "Symbolic Link".  
  
Symbolic link будет создана в этой папке/диске.  
  
Удаление Symbolic link не приводит к удалению исходной папки/файла, НО если открыть Symbolic link и в ней удалить папки/файлы, то они удаляться из исходной папки.
