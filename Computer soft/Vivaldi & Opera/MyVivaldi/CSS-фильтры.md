### Подключение css-фильтров  
  
1. Скачать один из предложенных ниже css-файлов или создать его в любом текстовом редакторе. Файл должен иметь расcширение "css"  
2. Если сами создаёте css-файл, то в него нужно записать требуемые css-правила  
3. Скопировать этот файл в папку "...\Vivaldi\Application\*версия браузера*\resources\vivaldi\userfiles"  
4. Браузер перезапускать не надо, фильтры сразу появятся в списке
