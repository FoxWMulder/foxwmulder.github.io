Сравнение скорости работы способов проверки файла на существование с помощью [GetFileAttributesEx](../../Handbook/Functions%20&%20Procedures/G/GetFileAttributesEx), [FindFirstFileEx](../../Handbook/Functions%20&%20Procedures/F/FindFirstFileEx), [FileExists](../../Handbook/Functions%20&%20Procedures/F/FileExists), [FileAge](../../Handbook/Functions%20&%20Procedures/F/FileAge).  
  
```ad-code

title: Код проверки файла на существование  
  
```pascal  
TStopwatch.Start('while FindFirstFileEx');  
var i2:Cardinal:=0;  
while i2<200 do begin //повторяем 200 раз  
var i:Cardinal:=20;  
while i<8020 do begin //8000 файлов  
 if FileExistsX(TexXEditor1.GetText(7,i)) then begin  
 end;  
 Inc(i);  
end;

end;  
TStopwatch.Stop('while FindFirstFileEx');  
TStopwatch.Show;  
```

FindFirstFileEx показал неожиданно плохие результаты, хотя в интернете я нашёл информацию что эта фукнция рабюотает быстрее чем FileExists. Возможно зависит от сценариев использования.  
  
Берём самый быстрый вариант. Использовалась следующая функция.  
  
```ad-code  
collapse: none  
title: Code  
  
```pascal  
function FileExistsX2(const filename:String):Boolean;  
var fad: TWin32FileAttributeData;  
begin  
if GetFileAttributesEx(PWideChar(filename), GetFileExInfoStandard, @fad) then begin  
 Result:=True;  
 end else begin  
 Result:=False;  
end;  
end;  
```  
  
Можно ли ещё увеличить её скорость?  
  
```ad-code  
collapse: none  
title: Code  
  
```pascal  
function FileExistsX2(const filename:String):Boolean;  
var fad: TWin32FileAttributeData;  
begin  
Result:=GetFileAttributesEx(PWideChar(filename), GetFileExInfoStandard, @fad);  
end;  
```  
  
 Думаю так будет быстрее, хотя результат отличается незначительно.  
   
	while GetFileAttributesEx: 9.2873 seconds, 7104078 ticks, call: 1  
  
Представленная выше функция не умеет работать с путями длиной более 255. Поэтому доработка (src [Функция GetFileAttributesExW (fileapi.h)](https://learn.microsoft.com/ru-ru/windows/win32/api/fileapi/nf-fileapi-getfileattributesexw)):  
  
```ad-code  
collapse: none  
title: Code  
  
```pascal  
function FileExistsX4(const filename:String):Boolean;  
var fad: TWin32FileAttributeData;  
begin  
Result:=GetFileAttributesEx(PWideChar('\\?\'+filename), GetFileExInfoStandard, @fad);  
end;  
```  
  
Но тут я столкнулся с невероятной (для меня) особенностью. Ниже два варианта, первый в определённом сценарии, давал рандомные результаты.  
  
```ad-code  
collapse: none  
title: Code  
  
```pascal  
function FileExistsX(const filename:String):Boolean;  
var fad: TWin32FileAttributeData;  
begin  
Result:=Windows.GetFileAttributesEx(PWideChar('\\?\'+filename), GetFileExInfoStandard, @fad);  
end;  
```  
  
```ad-code
