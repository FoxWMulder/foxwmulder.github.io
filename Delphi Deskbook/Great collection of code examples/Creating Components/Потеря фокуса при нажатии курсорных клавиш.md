При создание компонента на базе TCustomControl, даже если компоненту передать фокус (SetFocus), при нажатие на курсорных клавиш на клавиатуре фокус переходит другим компонента (таким как TEdit). Чтобы исправить этого надо в самом компоненте добавить:  
  
```ad-code  
collapse: none  
title: Code  
  
```pascal  
protected  
  procedure WndProc(var Message: TMessage); override;  
    
procedure TFocusableImage.WndProc(var Message: TMessage);  
begin  
  if Message.Msg = WMGETDLGCODE then  
  begin  
    // Вот это главное — говорим Windows: я хочу стрелки, все клавиши и символы  
    Message.Result := DLGCWANTARROWS or DLGCWANTALLKEYS or DLGCWANTCHARS;  
    Exit;  // не отдаём дальше  
  end;  
  
  inherited WndProc(Message);  
end;    
```
